### 2. Какие сетевые службы в ней разрешены?
В ходе сканирования были обнаружены следующие основные открытые порты и службы (характерные для Metasploitable):

### 3. Какие уязвимости были обнаружены?
На основе полученных версий служб были найдены следующие критические уязвимости в базе Exploit-DB:

1. **vsftpd 2.3.4 - Backdoor Command Execution**  
   - **Описание:** В этой версии FTP-сервера присутствует бэкдор, позволяющий выполнить произвольный код с правами root при попытке входа с именем пользователя, заканчивающимся на `:)`.
   
2. **UnrealIRCd 3.2.8.1 - Backdoor Command Execution**  
   - **Описание:** Популярный IRC-сердер содержал модифицированный исходный код с бэкдором, позволяющим удаленно выполнять команды через специальный запрос.

3. **Samba 3.0.20 - Remote Code Execution (CVE-2007-2447)**  
   - **Описание:** Уязвимость в скрипте `username map script` позволяет выполнить произвольные команды без аутентификации через внедрение мета-символов в имя пользователя.

## Задание 2: Сканирование в различных режимах и анализ трафика

### 1. Команды для сканирования
Для проведения сканирования в разных режимах использовались следующие команды (требуют прав root):
- **SYN scan:** `sudo nmap -sS [IP-адрес_Metasploitable]`
- **FIN scan:** `sudo nmap -sF [IP-адрес_Metasploitable]`
- **Xmas scan:** `sudo nmap -sX [IP-адрес_Metasploitable]`
- **UDP scan:** `sudo nmap -sU -p 53,137,161 [IP-адрес_Metasploitable]` *(выборочные порты для ускорения)*

### 2. Чем отличаются эти режимы сканирования с точки зрения сетевого трафика?
- **SYN-сканирование (`-sS`)**: Сканер отправляет TCP-пакет с установленным только флагом **SYN**. Это инициирует рукопожатие, но не завершает его.
- **FIN-сканирование (`-sF`)**: Сканер отправляет TCP-пакет с установленным только флагом **FIN** (имитируя корректное завершение соединения).
- **Xmas-сканирование (`-sX`)**: Сканер отправляет TCP-пакет с установленными флагами **FIN, PSH и URG** одновременно. Пакет "подсвечивается" флагами, как рождественская елка.
- **UDP-сканирование (`-sU`)**: Сканер отправляет пустые (или с минимальной полезной нагрузкой) **UDP-пакеты** на целевые порты, так как UDP не имеет флагов соединения, как TCP.

### 3. Как отвечает сервер?
- **При SYN-сканировании**: 
  - *Открытый порт:* Сервер отвечает пакетом **SYN/ACK**. Сканер в ответ отправляет **RST**, чтобы разорвать соединение до его установки (half-open scan).
  - *Закрытый порт:* Сервер отвечает пакетом **RST**.
- **При FIN- и Xmas-сканировании** (согласно RFC 793):
  - *Открытый порт:* Сервер **игнорирует** пакет (ответа нет). Это позволяет обойти простые stateless-межсетевые экраны.
  - *Закрытый порт:* Сервер отвечает пакетом **RST**.
- **При UDP-сканировании**:
  - *Открытый порт:* Ответа **нет** (или приходит специфичный ответ от UDP-службы, если она настроена отвечать).
  - *Закрытый порт:* Сервер (или промежуточный маршрутизатор) возвращает ICMP-сообщение типа 3, код 3 (**Port Unreachable**).
